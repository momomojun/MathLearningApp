## 2. P0-3 覆盖明细

### 模板解析器

- 全部已支持指令：chapter、section、subsection、text/markdown、定义/定理/推论/命题、题目/解析、图片/figure、表格、代码、视频及交互模块。
- 题目旧格式默认值、旧视频权限字段和 figure/markdown 别名。
- 空值、数字、未知指令和没有前置块的 solution 不会导致解析器崩溃。

### 本地状态

- 已读、最近学习、按类型读取、重复小节去重及最多 8 条限制。
- 课程收藏的添加/取消，清除历史时保留收藏。
- 已做、做错、习题收藏、错题本添加/移除和单题重置。
- localStorage 内容损坏或结构错误时恢复为空状态。

### API

- Token 请求头。
- 401 结构化错误和登录失效事件。
- 字段错误文案与空成功响应。
- 网络失败、外部取消和 15 秒默认超时分别分类。

### 浏览器流程

- 使用模拟 API 完成登录、进入知识库、打开课程、切换小节、自动标记已读和收藏。
- Axe 对关键学习页检查无可访问性违规。
- 360、768、1024、1440 px 均无页面级横向溢出；长公式纳入用例。
- Tab 键可以进入交互元素并显示焦点。

## 4. 尚未完成的验收与可复现任务

本轮回归曾发现并已修复以下代码缺陷：

- 辅助文字和收藏状态颜色未达到 WCAG AA 对比度，已统一加深并由 Axe 复验通过。
- 页面同时存在外层和内容层两个 `<main>`，已改为单一顶层 main landmark。
- API 原来只有主动取消，没有独立超时状态；现在默认 15 秒超时并返回 `kind: timeout`。

### QA-001：准备真实视频验收内容

- 优先级：P1，试运行前完成。
- 现状：已发布的 `calculus-limits-sequence` 视频指令地址为空，只能验证占位状态。
- 需要：在后台加入一条可播放 MP4，并设置封面、试看秒数和 `member` 权限。
- 验收：非会员播放到试看时限后出现会员提示；会员可继续播放；切换页面后播放器停止。

### QA-002：准备完整内容模块展示小节

- 优先级：P1，内容运营验收前完成。
- 现状：当前数据库内容没有已发布的代码块、Function Explorer、GeoGebra、Desmos 示例；种子文件与当前数据库内容存在版本差异。
- 需要：在后台新建一节“组件验收示例”，集中放入 `@code`、`@interactive function`、`@interactive geogebra`、`@interactive desmos`。
- 验收：代码块可横向滚动；函数滑块能更新图像；外部交互有地址时加载 iframe，无地址时显示清晰占位状态。

> 不建议直接在现有数据库执行覆盖式重新导入。先备份并确认后台已编辑内容是否需要保留，再决定更新种子数据或手工补齐示例。
