# MathAPP 知识库/习题库内容维护说明

课程内容现在存在数据库里，通过 Django 后台（`/admin/`）录入和维护，不再靠改前端文件。前端只负责展示，会按需向后端要数据。

## 1. 数据结构

三张表，一层套一层：

```text
课程 Course
  └─ 章 Chapter（分两种类型：知识库 / 习题库）
       └─ 小节 Section（真正的正文所在，一个知识点或一组习题）
```

- **课程**：标题、副标题、适合人群、简介、排序、是否上线。
- **章**：属于哪门课、类型是"知识库"还是"习题库"、章标题、排序；习题库类型的章可以填一个"题量说明"（比如"86 题"），知识库类型不用填。
- **小节**：属于哪一章、标题、一句话简介、访问权限（免费/会员）、排序、是否上线，以及正文内容。

正文内容还是用原来那套模板指令写（`@chapter`/`@section`/`@problem`/`@solution` 等），这部分完全没变，见第 4 节。

## 2. 在后台录入内容

打开 `http://127.0.0.1:8000/admin/`，左侧菜单能看到"课程内容"分组，下面是"课程""章""小节"三个入口。

**新增一门课程：**

1. 进入"课程" → 新增，填标题、副标题、适合人群、简介、排序，保存。
2. 保存后的编辑页面下方会有"章"的内联表格，可以直接在这里加章，也可以单独进入"章"页面加。

**给某门课新增一章：**

1. 进入"章" → 新增，选择所属课程、类型（知识库/习题库）、章标题、排序。
2. 知识库类型的章不用填"题量说明"；习题库类型建议填一下，比如"86 题"，前端课程卡片会显示这个。

**给某一章新增一个小节（真正写内容的地方）：**

1. 进入"小节" → 新增，选择所属章节、填标题、一句话简介、访问权限（免费/会员）、排序。
2. "正文（模板指令）"这个大文本框里，按第 4 节的指令写讲义或题目。
3. 保存。

**改内容**：直接在后台找到对应的"小节"，改"正文（模板指令）"文本框，保存即可，不用重新部署前端，前端下次请求就能拿到最新内容。

**下线内容**：把课程/章/小节的"是否上线"勾选去掉，前台立刻看不到，数据不会丢，随时可以再勾选恢复。

## 3. 权限怎么控制

小节的"访问权限"字段选"会员"，前台没开会员的用户会看到锁定提示，登录+开通会员后才能看到正文。这个校验前后端都做：前端根据这个字段决定是否显示锁定页；后端接口也会在真正返回正文前再查一次用户是否是会员，所以就算有人直接绕过前端调接口，也拿不到没权限的内容。

## 4. 支持的模板指令

正文字段里可以用这些指令（跟以前完全一样）：

```text
@chapter 编号 | 章标题
@section 编号 | 节标题
@subsection 编号 | 小节标题

@text 标题
普通正文，支持 Markdown 和 LaTeX。

@def 编号 | 标题
定义块。

@theorem 编号 | 标题
定理块。

@corollary 编号 | 标题
推论块。

@proposition 编号 | 标题
命题块。

@problem 例题 1 | 计算题 | 基础 | 数列极限,同阶无穷大 | 入门例题
题目卡片。竖线后面的字段依次是：题型、难度、知识点、标签。旧写法 `@problem 例题 1` 仍然可用，默认按“计算题 / 基础”处理。

@solution 解析
紧跟在定义、定理、命题或题目之后，会生成可折叠解析/证明。

@image 标题 | 图片地址 | 图注 | alt | 宽度
插图模块。宽度可写 wide、medium、small。前端会自动懒加载，点击图片可以放大预览，图片加载失败时会显示提示。

@table 标题 | 说明
| 列1 | 列2 |
| --- | --- |
| A | B |

@code 标题 | js | 说明
console.log('hello')

@interactive-sine 标题 | 说明
正弦曲线交互模块。

@interactive sine | 标题 | 说明
同样会渲染正弦曲线交互模块。

@interactive function | 标题 | 说明
expression: a*x*x + b*x + c
a: -5,5,0.1,1
b: -5,5,0.1,0
c: -5,5,0.1,0
xMin: -6
xMax: 6
yMin: -8
yMax: 8

函数图像交互模块。`expression` 支持 `x`、自定义参数和常用函数：`sin`、`cos`、`tan`、`sqrt`、`log`、`exp`、`pow`、`abs` 等。参数行格式是 `最小值,最大值,步长,初始值`。

@interactive geogebra | 标题 | 说明
src: GeoGebra 嵌入地址

@interactive desmos | 标题 | 说明
src: Desmos 嵌入地址

GeoGebra/Desmos 模块会按 `src` 渲染 iframe；暂时没有地址时会显示占位提示。

@interactive 标题 | 说明
通用交互模块占位。可以把几何作图、函数图像、向量演示等自定义 Vue 交互组件挂到这里。

@video 标题 | 视频地址 | 说明 | 封面图地址 | 试看秒数 | 权限
视频播放窗口。视频地址可以是 mp4/webm/ogg 文件，也可以是 B 站、腾讯视频、YouTube 等平台提供的 iframe 嵌入地址。权限可写 `member`，mp4/webm/ogg 支持按“试看秒数”试看，到点后会提示开通会员；iframe 无法精确控制试看，非会员会直接看到会员提示。
```

公式直接写正常的单反斜杠 LaTeX：

```text
行内：$a_n = 1/n$

块级：
$$
\lim_{n\to\infty}\frac{1}{n}=0
$$
```

## 5. 本地开发：一键导入示例内容

刚拉下项目、数据库是空的时候，跑一下：

```powershell
.\.venv\Scripts\Activate.ps1
python manage.py migrate
python manage.py seed_demo_content
```

会把微积分/线性代数/概率统计 3 门课、7 个小节的示例内容导入数据库，方便本地开发时前端有数据可看。这个命令可以重复执行，不会重复创建。

## 6. 给开发看的接口说明

前端通过这几个接口拿内容，正文是懒加载的（进课程时不会把所有小节正文都拉下来，点开哪节才请求哪节）：

```text
GET /api/content/courses/                课程列表（卡片用，不含章节）
GET /api/content/courses/<slug>/         课程详情（章节+小节元信息，不含正文）
GET /api/content/sections/<slug>/        单个小节正文（会员内容会做权限校验）
```

对应代码：`content/models.py`、`content/serializers.py`、`content/api.py`、`content/urls.py`；前端调用封装在 `frontend/src/api.js` 的 `content` 对象里，页面逻辑在 `frontend/src/views/KnowledgePage.vue` 和 `ExercisesPage.vue`。
